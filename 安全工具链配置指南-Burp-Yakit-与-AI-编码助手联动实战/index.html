安全工具链配置指南：Burp、Yakit 与 AI 编码助手联动实战

AI安全 Burp Suite Yakit Claude Code Codex MCP 工具配置
工具实践
发布日期:   2026-06-04

本文记录我个人搭建的安全工具链配置过程，覆盖 Burp Suite、Yakit 与 Claude Code、Codex 的 MCP 联动方案。环境为 Windows 11 + bash shell。

一、整体架构

这套工具链的核心思路是：通过 MCP（Model Context Protocol）协议，让 AI 助手直接调用安全工具的 API，实现”用自然语言驱动工具”的工作流。

┌─────────────┐     MCP      ┌──────────────┐
│ Claude Code │ ◄──────────► │ Burp Suite   │
│   / Codex   │              │  (MCP Server)│
└─────────────┘              └──────────────┘
       │                            │
       │ MCP                  ┌─────┴─────┐
       ▼                      ▼           ▼
┌─────────────┐        ┌─────────┐  ┌──────────┐
│   Yakit     │        │ Proxy   │  │ Scanner  │
│(yaklang MCP)│        │ History │  │  APIs    │
└─────────────┘        └─────────┘  └──────────┘

各组件作用：

组件 作用 状态
Burp MCP 代理流量分析、被动/主动扫描、漏洞验证 Active @ 127.0.0.1:9876
Yakit (yaklang) 端口扫描、PoC 检测、Web Fuzzer、暴力破解 Active @ D:\yingyong\yakit
Kimi WebBridge 浏览器自动化（替代 Claude in Chrome） Active @ localhost:10086
Claude Code AI 编码助手，通过 MCP 调用上述工具 CLI 主入口
Codex OpenAI 的命令行编码助手 备用方案

二、Burp Suite MCP 配置

2.1 前置要求

  • Burp Suite Professional / Community（Pro 功能更全）
  • Burp 的 AI Agent MCP Server 插件（或原生 MCP 支持）

2.2 启动 MCP Server

Burp 的 MCP Server 默认以 SSE（Server-Sent Events） 方式暴露：

Endpoint: http://127.0.0.1:9876/
Transport: SSE

启动方式：

  1. 打开 Burp Suite
  2. 进入 Extender → BApp Store，搜索 “AI Agent” 或 “MCP”
  3. 安装并启用后，在插件配置中开启 MCP Server
  4. 确认端口监听：netstat -ano | findstr 9876

2.3 测试连通性

# 检查 SSE 端点是否响应
curl -s http://127.0.0.1:9876/health

# 或使用 Claude Code 内置检测
claude mcp test burp

三、Yakit / yaklang MCP 配置

3.1 前置要求

  • Yakit 客户端已安装
  • yak-engine 引擎路径确认：D:\yingyong\yakit\yakit-projects\yak-engine\yak.exe

3.2 启动 yaklang MCP

Yakit 的 MCP 通常通过 yak-engine 的命令行模式启动：

# 进入 yak-engine 目录
cd "/d/yingyong/yakit/yakit-projects/yak-engine"

# 启动 MCP 服务（示例命令，具体参数参考 Yakit 文档）
./yak.exe mcp --port 50051

或者通过 Yakit GUI：

  1. 打开 Yakit → 设置 → 高级设置
  2. 找到 MCP Server 选项，勾选启用
  3. 配置监听地址（默认 127.0.0.1:50051）

3.3 验证工具可用性

# 检查 yak 引擎版本
"D:\yingyong\yakit\yakit-projects\yak-engine\yak.exe" version

# 简单端口扫描测试（本地测试用）
yak.exe port-scan --target 127.0.0.1 --port 80,443,8080

四、Claude Code MCP 配置

4.1 配置文件位置

Claude Code 的 MCP 配置在用户目录下的 settings.json：

Windows: %USERPROFILE%\.claude\settings.json
Linux/macOS: ~/.claude/settings.json

4.2 添加 MCP Servers

编辑 settings.json，在 mcpServers 字段中添加：

{
  "mcpServers": {
    "burp": {
      "command": "python",
      "args": [
        "C:\\Users\\32550\\.claude\\tools\\burp_mcp_client.py"
      ],
      "env": {
        "BURP_MCP_URL": "http://127.0.0.1:9876"
      }
    },
    "yaklang": {
      "command": "D:\\yingyong\\yakit\\yakit-projects\\yak-engine\\yak.exe",
      "args": ["mcp", "--port", "50051"]
    }
  }
}

配置说明：

  • burp：通过 Python 桥接脚本连接 Burp 的 SSE 端点
  • yaklang：直接调用 yak 引擎的 MCP 子命令
  • env 中可配置 Burp 的连接地址

4.3 验证配置

# 列出已配置的 MCP 服务器
claude mcp list

# 测试单个连接
claude mcp test burp
claude mcp test yaklang

# 进入交互模式，直接调用工具
claude
> /mcp burp scan http://target.com

五、Codex CLI 配置（备用方案）

Codex 是 OpenAI 的命令行编码助手，同样支持通过 MCP 扩展能力。

5.1 安装 Codex

# 通过 npm 安装
npm install -g @openai/codex

# 或通过 pip
pip install openai-codex

5.2 配置 API Key

# 设置 OpenAI API Key
codex config set api_key sk-xxxxxxxxxxxxxxxx

# 或使用环境变量
export OPENAI_API_KEY=sk-xxxxxxxxxxxxxxxx

5.3 接入 MCP（如支持）

Codex 的 MCP 支持尚在演进中，当前可用方案：

  1. 通过 Claude Code 的桥接：在同一个项目中同时使用 Claude Code 和 Codex
  2. 独立调用：Codex 负责代码生成，Claude Code 负责工具调用
# 示例：Codex 生成 PoC 代码，Claude Code 调用 Yakit 执行
codex "写一个检测 Redis 未授权访问的 Python 脚本"
# 生成代码后，用 Claude Code 的 yaklang MCP 执行扫描

七、常见问题

Q1: Burp MCP 连接失败？

排查：

  1. 确认 Burp 已启动且插件已加载
  2. 检查 127.0.0.1:9876 是否被占用：netstat -ano | findstr 9876
  3. 查看 Burp 的 Extender → Output 面板是否有错误日志
  4. 防火墙是否拦截了本地回环地址

Q2: Yakit MCP 端口冲突？

解决：

# 更换监听端口
yak.exe mcp --port 50052

# 同步更新 Claude Code 的 settings.json

Q3: Claude Code 不识别 MCP 工具？

排查：

  1. 确认 settings.json 语法正确（JSON 格式）
  2. 重启 Claude Code 进程
  3. 检查 claude mcp list 是否列出配置
  4. 查看 Claude Code 日志：%USERPROFILE%\.claude\logs\

Q4: 中文路径问题？

已知问题：bash 中直接输入中文路径可能导致 EOF 错误。

规避方案：

# 使用短路径或环境变量
export YAK_PATH="/d/yingyong/yakit/yakit-projects/yak-engine"
$"YAK_PATH"/yak.exe mcp --port 50051

八、安全与合规提醒

  1. 授权边界：所有扫描和测试行为必须在授权范围内进行，严禁对非自有资产进行探测
  2. 数据隐私：Burp 抓包可能包含敏感信息，注意本地存储安全
  3. AI 输出校验：AI 生成的 PoC 代码需人工审核后再执行，避免误操作
  4. 环境隔离：建议在虚拟机或 Docker 中运行高风险测试
