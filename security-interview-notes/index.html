33 有了解HTTPS的原理，你说一说HTTPS的原理

HTTPS 是在 HTTP 基础上通过 TLS/SSL 加密传输，保证数据机密性、完整性和身份认证。客户端访问服务器时，先进行 TLS 握手，服务器提供数字证书验证身份，双方通过非对称加密交换对称会话密钥，然后使用对称加密进行数据传输。TLS 1.3 进一步优化握手，减少延迟并提高安全性

42 了解过反序列化漏洞的产生原因吗？

用户可以通过 HTTP、或其他网络协议向服务器发送任意的序列化字符串或字节码，服务器未经严格验证就进行了反序列化

43 用java chains讲一下这个java反序列化漏洞的产生原因

Java 反序列化漏洞的产生，核心是程序反序列化了来自不可信来源的对象，触发了对象中的魔术方法和依赖库中的 Gadget Chain，最终导致攻击者能够执行任意代码

44 说一下CB 链

CB 链依赖 Commons-BeanUtils，通过 BeanComparator 或 PropertyUtilsBean 的方法链触发执行

CB 链不依赖特定的 CC 版本（CC3.1 或 4.0），只要目标环境有 commons-beanutils 且没有对 BeanComparator 做黑名单防御，成功率极高
